# 设计规范（参考 FEEI.CN 提炼）

来源：对 `/Users/systemd/AgentSpace/repository/FEEI.CN` 的主题参数做**分析提炼**（色板、字号刻度、行高、间距、栅格、断点、交互模式），用于我们**独立实现**自己的样式。

注意：FEEI.CN 仓库无 LICENSE 文件（GitHub 识别为 None，页脚声明 All Rights Reserved）。本文只记录**参数与模式**，不复制其代码文件；我们用自己的类名与结构重写。

## 一、色板

| 语义 | 亮色 | 暗色 |
| :--- | :--- | :--- |
| 页面背景 | `#fafafa` | `#111111` |
| 卡片/表面 | `#ffffff` | `#181818` |
| 侧栏轨道 | `#f5f5f3` | `#181818` |
| 主色（"品牌"） | `#262626` | `#ededed` |
| 正文 | `#262626` | `#ededed` |
| 次级文字 | `#666666` | `#a3a3a3` |
| 弱化文字 | `#999999` | `#737373` |
| 边框 | `#e5e5e5` | `#2a2a2a` |
| 链接下划线 | `#bdbdbd` | `#525252` |

设计原则：**无彩色强调色**，品牌感完全由排版和留白承担。

## 二、排版刻度

- 基础字号 **15px**（93.75%），代码 **95%**
- 行高：正文 **1.85**，标题 **1.22**
- 段落下间距 **2rem**，列表项间距 **0.3rem**，标题下间距 **0.7rem**
- 标题刻度：h1 **2rem** / h2 **1.38rem** / h3 **1.15rem** / h4 **1.05rem** / h5 **1rem** / h6 **0.95rem**
- 正文（文档区）：衬线宋体系 `'Songti SC', 'STSong', 'SimSun', serif`，字号 **1.05rem**
- UI：系统无衬线（Inter + PingFang SC + Noto Sans SC…）
- 引用块：楷体系 `'Kaiti SC', 'STKaiti', 'KaiTi', 'BiauKai', serif`，**1rem**

## 三、布局栅格

- 文档容器宽 **1360px**（三栏合计）
- 左侧栏宽 **260px**，背景用"侧栏轨道"色
- 断点：**≥997px** 三栏（侧栏 + 正文 + 右侧目录）；**≤996px** 折叠；**≤640px** 移动
- 首页：hero 上下内边距 `clamp(1.25rem, 4vh, 2.5rem)`；标题 2rem；引导语 1rem（最大 680px）；动作行 0.88rem / 间距 `.75rem 1.5rem`
- 首页精选列表：编号 0.72rem、标题 1.12rem、描述 0.85rem、分类标签 0.7rem、行内边距 `.5rem 0 1rem`、"最近更新"双栏间距 3rem

## 四、组件与交互模式

| 模式 | 做法 |
| :--- | :--- |
| 链接 | 继承正文色 + 1px 下划线（弱灰色），hover 变主色且下划线转 `currentColor`，过渡 140ms |
| 标题锚点 | 默认不可见，hover/focus 时以 0.42 透明度出现 |
| 标题编号 | h2 = `序号.`，h3 = `父序号.子序号.`，数字用等宽数字、同色 26% 透明 |
| 目录（TOC） | 右侧栏，整体 0.88 透明度，随滚动高亮当前小节 |
| 左侧导航 | 可隐藏 + 分类自动折叠；导航栏分组下拉（带图标）+ 站内搜索 + 深浅色切换；有滑动指示器 |
| 面包屑 | 透明背景、去内外边距、弱化色 |
| 图片 | 骨架屏/错误态、圆角边框、图注居中 |
| 文章元信息 | 显示"最后更新/复核时间"、提供"复制 Markdown" |
| 首页 | 名字 + 一句定位 + 引导语 + 三个动作（从这里开始 / 关于 / RSS）+ 最近关注 + 「从这里开始」精选 + 「最近更新」双栏 |

## 五、我们要做的取舍

**建议照搬**：字号刻度、行高、段落与列表间距、三栏栅格与断点、链接下划线规则、标题编号、标题锚点、目录高亮、面包屑、图片与代码块样式、文章"最后更新"与复制原文。

**暂不照搬**：无彩色灰阶配色与全站衬线正文（上次试过、观感偏冷）；`:has()` 重度依赖的实现方式；他的个人数据看板与生活系统内容。

**我们的实现原则**：用自己的类名与选择器重写；配色作为可切换的一层（先保留现有蓝色链接的暖色方案，等确认后再评估是否切灰阶）。
